# Final STL Storage Organizer

Features:
- STL upload
- IndexedDB persistence
- Folder organization
- Subfolders
- Rename/delete folders
- Rename/delete files
- Tags
- Search
- Sorting
- STL viewer
- Local persistent library

Deploy:
- Upload to GitHub
- Import into Vercel
- Framework preset: Vite
- Build command: npm run build
- Output directory: dist
